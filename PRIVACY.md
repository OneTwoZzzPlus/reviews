# Privacy Policy for Reviews Extension

This extension ("Reviews") respects user privacy.

1. Data Collection: The extension does not collect, store, or transmit any personally identifiable information, passwords, session tokens, or browsing history.
2. Data Storage: All settings and cached review data are saved locally on your device via Chrome Local Storage API and are never transferred to third parties.
3. Network Requests: Network requests are made solely to fetch teacher review data from the backend API (reviews.work.gd).
4. Contact: If you have any questions, you can open an issue at https://github.com/OneTwoZzzPlus/reviews/issues
